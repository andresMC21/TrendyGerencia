# HU-11: Consultar un producto

**Rol:** visitante · **Prioridad:** muy alta

Como visitante, quiero ver la información detallada de un artículo para decidir si me interesa comprarlo o intercambiarlo.

## Criterios de aceptación y cómo se cumplen

| # | Criterio | Implementación | Evidencia automatizada |
|---|---|---|---|
| 1 | Al abrir un producto existente se consultan sus datos | `GET /api/products/:id` (público) devuelve el producto con el perfil público del vendedor | e2e `GET /products/:id devuelve detalle con vendedor y suma visitas` |
| 2 | Cada consulta incrementa `viewsCount` | `ProductService.findOne` incrementa el contador en la base en cada consulta | mismo e2e (compara dos consultas seguidas); unitarias de `findOne` |
| 3 | Id con formato inválido: rechazado; inexistente: no devuelve producto | `ParseUUIDPipe` (400) y 404 si no existe o está retirado (REMOVED) | e2e `GET /products/:id valida UUID y 404` |

## Web

`/producto/:id`: título, precio, descripción, condición, barrio, fecha, visitas, favoritos y vendedor (con su reputación). Un id inválido o inexistente muestra «Este producto no existe o ya no está publicado».

> En desarrollo (`npm run dev`) React StrictMode monta la página dos veces y cada visita suma 2 a `viewsCount`; en la versión compilada suma 1.

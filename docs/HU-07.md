# HU-07: Consultar otro perfil

**Rol:** usuario autenticado · **Prioridad:** alta

Como usuario, quiero consultar el perfil y la reputación de otra persona, para tomar mejores decisiones antes de realizar un intercambio.

## Criterios de aceptación y cómo se cumplen

| # | Criterio | Implementación | Evidencia automatizada |
|---|---|---|---|
| 1 | Con sesión válida puedo consultar el perfil de otra persona | `GET /api/user/:id` exige JWT (`@Auth()`): 401 sin token o con token inválido, 404 si la cuenta no existe o está inactiva, 400 si el id no es UUID | e2e `HU-07 · criterio 1`; Postman «GET /user/:id sin token → 401» |
| 2 | La respuesta presenta `ratingAverage` y `reviewsCount` | Siempre numéricos (0 si no tiene reseñas). Además: las 5 reseñas más recientes (`recentReviews`), `availableProductsCount` y `memberSince` | unitarias `HU-07 · … criterio 2`; e2e `criterio 2` y «tras la reseña del comprador, el perfil del vendedor muestra su reputación» |
| 3 | No se exponen contraseñas ni datos internos de autenticación | La respuesta usa `PublicProfileDto`, que solo tiene id, nombre, presentación, foto, verificación y reputación. No incluye `password`, `email`, `role`, `isActive` ni `tokenVersion`; las reseñas muestran solo el nombre de quien las escribió | unitarias `HU-07 · no expone…`; e2e `criterio 3`; Postman «Criterio 3: sin contraseña…» |

Ejemplo de respuesta:

```json
{
  "id": "33333333-3333-4333-8333-333333333333",
  "fullName": "Ana Gomez",
  "info": "Vende productos de segunda mano en Granada",
  "photoUrl": null,
  "verificationStatus": "VERIFIED",
  "ratingAverage": 5,
  "reviewsCount": 1,
  "availableProductsCount": 1,
  "recentReviews": [
    { "rating": 5, "comment": "Comunicacion clara…", "reviewerName": "Carlos Ruiz", "createdAt": "…" }
  ],
  "memberSince": "…"
}
```

## Web

- Nueva página **`/usuario/:id`** (requiere sesión; sin sesión lleva a «Ingresar»): foto o iniciales, nombre, verificación, calificación grande con estrellas y número de reseñas, presentación, productos disponibles, «Miembro desde» y las reseñas recientes.
- Si la persona no tiene reseñas: «Sin calificaciones todavía». Si el perfil no existe o está inactivo: «Este perfil no existe o la cuenta ya no está activa». Si es el propio perfil: «Así ven tu perfil las demás personas», con enlace a Mi perfil.
- Se llega desde:
  - el detalle de un producto, con **Ver perfil y reputación →** en el recuadro del vendedor;
  - una transacción, pulsando el nombre del comprador o del vendedor.

## Validación manual

1. Ingresar con `maria.compradora@trendy.local` / `Maria2026`.
2. Abrir **Bicicleta urbana restaurada** y pulsar **Ver perfil y reputación →**: se ve Ana Gomez, Identidad verificada, **5.0 ★★★★★ · 1 reseña**, 1 producto disponible y la reseña de Carlos Ruiz. No aparece su correo.
3. Abrir el perfil de Camilo (desde **Escritorio de madera con cajones**): «Sin calificaciones todavía» y 2 productos disponibles.
4. Cerrar sesión y abrir `/usuario/<id>`: lleva a **Ingresar**. Con la API, `GET /api/user/<id>` sin token responde 401.

## Cambio respecto a la versión anterior

`GET /user/:id` era público y devolvía el perfil completo (incluido el correo, el rol y el estado de la cuenta). Ahora exige sesión y devuelve solo el perfil público. El propio perfil completo sigue en `GET /user/me` (HU-03).
